# Privacy and Data Boundary

## 公共脚本处理什么

脚本只在用户明确运行后读取当前 Office 上下文、用户指定的本地文件、剪贴板或选区。公共脚本本身不包含网络上传地址，也不应静默上传文档。

## AI 功能边界

本公共包提供提示词和脚本创作材料，不替代产品的 AI 隐私策略。用户明确触发 AI 功能时，所选文本、提示词和必要上下文可能按产品版本的服务策略处理；敏感文档应优先使用本地只读或本地 Host 能力。

## Issue 和 Pull Request

公开讨论只能使用脱敏示例。不得提交客户文件、合同正文、个人信息、真实账号、内部路径、完整日志、崩溃转储、访问令牌或生产配置。

## 贡献者责任

贡献者应确认脚本、提示词和示例不包含第三方受限内容或未经授权的业务数据。发现误发布时，应立即停止传播并通过私密安全渠道报告。
