# Compatibility

## 当前公开口径

- Windows 桌面版 Office。
- Microsoft Word、Excel、PowerPoint。
- Office 2010 及以上版本已完成兼容性测试。
- 支持的具体能力取决于当前 Office 应用、文档状态、选区状态和 Host API 版本。

当前不公开硬件最低参数。硬件差异主要会影响 Office 本身、文档规模、批处理数量和 AI 请求耗时；在形成可复现的基准测试矩阵前，不把推测值写成产品承诺。

## 报告问题时请提供

Office 应用和版本、32/64 位、Windows 版本、脚本名称、是否有活动文档/选区、期望结果、实际结果，以及已脱敏的 Host 返回值。
