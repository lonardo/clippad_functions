# Scene Profile Examples

examples/scene-profiles/ 中的 JSON 是“用户模板格式档案”结构示例，不是国家标准、行业标准、法律意见或正式公文规范。

## 使用方式

1. 用户在本地选择自己的 Word 样本文档；
2. Host 只提取格式字段，例如字体、段落、页边距和表格边框；
3. 用户确认来源、版本和适用文书类型；
4. 先生成预览，再应用到目标文档；
5. 保留业务文字、事实、金额、当事人、证据、附件和机构信息。

## 贡献边界

社区可以贡献格式字段、校验规则和 Schema 改进，但不得把真实单位模板、真实合同、真实法律文书或客户样本提交到公共仓库。所有 profile 都应保持 confirmedByUser=false，表示它们需要用户提供和确认实际模板。
