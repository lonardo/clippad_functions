# 使用大模型批量生成和修改 VBS

## 生成所需输入

大模型至少需要同时获得：

1. ../host/host-api-v1.json；
2. ../prompts/vbs-system-prompt.md；
3. 目标 Office 应用、文档状态、选区状态和输入输出约束；
4. 一个同类 Host 预设作为风格和错误处理示例；
5. 必须通过的静态检查和 smoke case。

## 批量流程

~~~text
需求清单
  -> 选择 Office 应用和脚本分类
  -> 注入 Host API v1 + 系统提示词
  -> 逐个生成 VBS
  -> 检查 Main、编码、Host 方法和危险 API
  -> fake Host 语法/结果 smoke
  -> 人工检查写入计划、备份和确认
  -> 只修复失败脚本
  -> 生成变更清单和版本号
~~~

## 批量修改规则

- 每次修改限定一个明确的规则，例如“把输出路径改为避免覆盖”，不要把无关重构混入批次。
- 保留脚本文件名、入口函数和元数据；如果行为改变，递增脚本版本。
- 先生成 diff 和失败清单，再接受自动修复。
- 任何会修改 Office 文档或本地文件的脚本都必须标记风险，并在提交前经过预览/确认。
- 大模型不得自动提交 Git、发布 Release 或切换 prod。
