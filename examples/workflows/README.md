# Workflow Examples

本目录的 JSON 文件用于说明输入、处理、条件和分段工作流结构。它们不包含账号、密钥、内部 URL 或备案/申报材料，也不嵌入 CreateObject、ADODB.Stream 或其他绕过 Host 的旧式执行代码。

建议先复制一份到测试环境，再根据当前 Host API 和模板版本调整。工作流示例本身不代表任何生产部署配置。

文件包括：

- file_batch_processing.json
- file_batch_process.json
- advanced_data_processing.json
- segmented_workflow.json
