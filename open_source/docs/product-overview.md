# Product Overview

OfficeAddin 是面向 Windows 桌面版 Word、Excel 和 PowerPoint 的 Office 插件。它把重复的 Office 操作整理成可复用的命令、Host-first VBS 和工作流，并可在用户明确触发时接入 AI 生成或修改。

## 适用环境

- Windows 桌面版 Office；
- Word、Excel、PowerPoint；
- Office 2010 及以上版本已完成兼容性测试；
- 本公共包面向脚本、提示词和文档创作，不包含私有客户端源码或生产服务。

## 低打扰设计

插件的设计目标是低常驻资源占用和低交互打扰：

- 本地能力优先，AI 只在用户明确触发时参与；
- 选区读取、路径预检和上下文摘要优先使用轻量 Host 方法；
- 写入操作采用预览、确认、备份和回滚路径；
- 批处理应有数量、时间和输出范围限制；
- 性能数据以实际测试矩阵为准，当前不发布未经验证的 CPU、内存和 IO 数值。

## 安装包边界

正式安装包通过独立的 GitHub Release 或官方渠道发布，安装包的产品使用许可与本目录的 Apache-2.0 公共材料分开。安装包发布时只附带必要的校验值、变更说明、兼容性和已知问题，不附带软著、ICP备案、专利或市场申报资料。
